# Neovim Cheatsheet

## Basic Neovim Stuff

`>` and `<` in visual mode indent/unindent stuff

`=` in visual mode formats stuff with indentation

`~` changes case, `U` makes uppercase, `u` makes lowercase in visual mode
`g~<movement>`, `gU<movement>`, `gu<movement>` for normal mode
