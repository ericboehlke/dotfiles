# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

## External dependencies

These are not installed by the config and must be set up on each machine:

- **zk**: `zk-nvim` only wraps the [`zk`](https://github.com/zk-org/zk) binary, so `zk` must be installed and on `PATH`.
- **Mermaid** (`mmdc`, puppeteer config, Chromium): see [MERMAID.md](MERMAID.md).
